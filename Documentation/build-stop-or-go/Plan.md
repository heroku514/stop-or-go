# Plan - Stop or Go

## Goal
Ship a free offline street-light app for kids, families, and seniors. The light moves only red, then yellow, then green, then red. A skip stays put.

## Approach
1. Write one Expo screen and the light rules.
2. Check the rules, then commit and push before the simulator run.
3. Build a Release binary and run the full simulator regression.
4. After every check passes, take three screenshots and submit build 1.
